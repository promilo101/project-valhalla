# Bot test report (100-wave test), version 0.20.0

5 raids, 141 waves in total. Average best wave 28.2, median 31. Reached wave 10: 100%, wave 20 (Fenrir beaten): 80%, wave 30: 60%, capped at 40: 20%.

The bot buys units for synergies, buys gear upgrades from the Merchant, takes boss gear when it is an upgrade, and uses battlefield events. "gear:none" never buys gear, "gear:focus" spends more on it, "events:none" ignores battlefield events.
